  "new_trade":
    "NO NEW TRADE"
    OR
    {
      "ticker": "string",
      "signal_source": "quant",
      "veto_check": "PASS — 无T1负面新闻" 或 "VETO — [具体新闻和理由]",
      "direction": "long",
      "confidence": 0到1之间的数字,
      "entry_price": 数字（直接使用第 3a 节值）,
      "stop_price": 数字（直接使用第 3a 节值）,
      "target_price": 数字（直接使用第 3a 节值）,
      "shares_to_buy": 整数（直接使用第 3a 节 sizing.shares_to_buy）,
      "strategy": "string（照搬第3a节值：trend_long / breakout_long / earnings_event_long）",
      "invalid_if": "使逻辑无效的具体条件"
    },

  "add_on_trades": [
    {
      "ticker": "string",
      "action": "ADD",
      "shares_to_buy": 整数,
      "fill_timing": "next_session_open",
      "decision_mode": "code_followthrough_addon",
      "reason": "照搬第3a-add节代码理由"
    }
  ],

  "add_on_vetoes": [
    {
      "ticker": "string",
      "reason": "T1灾难新闻否决理由"
    }
  ],

  "position_actions": [
    {
      "ticker": "string",
      "current_position": "long",
      "action": "HOLD | REDUCE | EXIT",
      "reason": "照搬第4节代码决策理由",
      "exit_rule_triggered": "NONE | HARD_STOP | ATR_STOP | TRAILING_STOP | SIGNAL_TARGET | PROFIT_TARGET | PROFIT_LADDER_50 | PROFIT_LADDER_30 | TIME_STOP | APPROACHING_HARD_STOP",
      "shares_to_sell": 整数或null,
      "decision_mode": "forced_rule | pending_unexecuted_action",
      "suggested_new_stop": 数字或null
    }
  ]
}

重要说明：
- 只输出 JSON，不要 markdown 代码块
- action=REDUCE 时 shares_to_sell 为必填（= 总股数 × suggested_reduce_pct / 100，向下取整）
- action=HOLD 或 EXIT 时 shares_to_sell 必须为 null
- 若无新交易，new_trade 设为字符串 "NO NEW TRADE"
- 若无加仓动作，add_on_trades 设为空数组 []
- 若无加仓否决，add_on_vetoes 设为空数组 []
- position_actions 必须包含所有持仓——即使操作为 HOLD
