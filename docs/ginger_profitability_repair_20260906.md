# Ginger 本轮改造记录

这轮把真实交易反馈、历史数据采集和研究执行三个环节接通，并完整验证了一个新策略想法。还没有证据说明系统已经能稳定赚钱。

1. **让日报看得到真实交易结果。** 新增只读券商盈亏汇总，接进日报和 `quant_signals`。只统计完整买卖、费用齐全的交易，订单费用只扣一次；缺数据明确显示不可用。修复了纸上策略指标覆盖交易日记统计、账本缺行却仍报完整收益、查询失败却刷新数据时间等问题。同一笔成交的版本回转也有了明确的新观测记录，重放旧采集不会把新状态改回去。

2. **修好近一个月没有更新的成交和订单。** 原代码一次请求两年历史，触发券商实际返回的单次 360 天限制。现在保留整个历史范围，分成 360、360、11 个自然日查询，每段状态单独记录，任何一段失败都不会报全部成功。真实接口已成功取回 698 条成交、740 条订单和 658 条订单费用记录，经济数据成功查询时间恢复到 2026-09-06 17:01 UTC。隔离账本与正式账本的最终事实逐项核对一致，原有八条 JSONL 账本的全部旧字节前缀保留。

3. **解除研究任务的旧阻塞。** 明确 Edge 工作树负责后续 V2 研究，root 负责生产维护，历史证据各自保留。已通过应用更新并回读验证实际自动任务配置，使它按研究优先级执行；旧分支分歧和不重叠的改动不再冻结全部研究。实验编号现在跨工作树、分支统一避重，并用共享锁保护；清理器不会再删除这个持久锁。此次独立实验已实际走通登记、认领、执行和收尾。

4. **淘汰一个没有优势的新策略。** 冻结规则后，测试了“美联储会议公告前一交易日开盘买 SPY、公告日开盘卖出”。共 10 次历史决策，扣除预设往返 0.10% 成本后，平均每次为 -0.136%，比事先固定的上一周对照差约 0.285 个百分点。按原定条件拒绝，没有看完结果再换参数、持有期或标的凑盈利。这个小样本结果只用于淘汰本次候选。

目前账本有 105 个带平仓链接的周期，只有 103 个买卖数量和费用完整、可以核对。后者毛交易盈亏为 **-$14,172.03**，订单费用 **$540.84**，扣订单费用后为 **-$14,712.87**。另 2 个因数量路径不完整被排除，13 个未闭环周期和历史起点不明的成交也没有冒充完整收益。这是账户交易的覆盖样本，未计全部持仓浮盈亏、股息、融资与借券成本，不能当成整个账户收益，也还不能归因于 Ginger 策略。

收益、采集、账本及日报的 92 项联合测试通过；跨工作树编号修复分别通过 root 23 项、Edge 27 项针对性测试，后续锁清理修复两边各通过 13 项测试。真实采集的最终成交、订单与费用逐项核对无差异；重复已提交采集零追加，写入中断后的状态恢复通过回归，旧账本和持仓文件保持完整。没有下单或开启新的实盘交易权限。
