## Post-Run Reflection

- Why did the result happen? Re-screened the six standalone accepted sleeves (266 rows, 133
  tickers, 14 evaluable cells) with the exp-20260612-027 ex-top-ticker robustness screen. Zero
  net-new survivors; both predicted failure modes hit. The two near-misses are the real content:
  (1) MACRO_RELIEF x mixed|balanced|normal has a STRONGER edge than the accepted iscf cell
  (edge +4.95pp, ex-top +3.26pp vs iscf +2.21pp) but only n=6, below the 12-row floor; (2) consensus
  x same cell fails exactly on APP concentration again. SEC_FTD_FINRA, with 121 rows (the most),
  produced no screenable cell — its state structure is weak or absent. mixed|balanced|normal is now
  the gold state confirmed across iscf, macro_relief, consensus, and several 027 near-misses: calm
  mid-trend balanced tape is where quality/leadership sleeves earn their edge.
- Which near-neighbor retry is now forbidden? Gate-4ing the MACRO_RELIEF cell now (n=6 is
  noise-fitting); lowering the row floor or relaxing the ex-top screen to manufacture survivors;
  retrying the consensus cell (APP); re-screening SEC_FTD_FINRA with a different classifier.
- What new evidence would justify a retry? MACRO_RELIEF x mixed|balanced|normal is a genuine
  forward-maturation lead (not accepted): re-screen once that sleeve accumulates >=12 closed rows in
  the state from forward default-off observation, then if it still clears ex-top, reserve a single
  frozen Gate 1-4 sleeve tilt (exp-20260613-005 template). A real multi-cell router needs >=2-3
  independently ex-top-clean cells with adequate sample; today there is 1 confirmed (iscf, accepted)
  + 1 thin lead (macro_relief) — not enough yet.
