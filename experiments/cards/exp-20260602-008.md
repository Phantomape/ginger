# Experiment Card: exp-20260602-008

## Summary

Commit bb4ced9e9 made the backtester source next_earnings_date/days_to_earnings from daily earnings snapshots, but exp-20260601-016/023 showed the 2024-2025 canonical-window snapshots are backfilled (midnight timestamps, first committed 2026-05-15; real-time captures only begin 2026-04-20, after all three windows end), so the canonical baseline silently drifted 1.5345 EV / 2,312.38 from the documented 7.8941 / 34,850.99 by sourcing earnings dates from non-PIT reconstructed data. Restoring calendar-only deterministic next_earnings_date/days_to_earnings in the backtester _earnings_dict_for (strict future > today; snapshot supplies only eps/surprise fields, never the earnings date) should reproduce the documented three-window baseline exactly, with zero production impact (run.py builds its own production earnings_data and does not call the backtester path).
