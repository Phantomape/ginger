# Experiment Card: exp-20260601-009

## Summary

Overnight vs intraday return decomposition on the broad 1446-ticker universe: the equity premium accrues mostly OVERNIGHT (prev_close -> open) while the intraday session (open -> close) is flat or negative (the overnight-return anomaly). Decomposing each ticker-days close-to-close return into overnight and intraday components and aggregating across the canonical 3 windows should show mean overnight return significantly positive (t>=2, majority windows) and materially larger than mean intraday return. This is a time-of-day structural mechanism orthogonal to the cross-sectional momentum that the prior ranking/reversal lines reduced to, and it has direct relevance to core entry/exit timing (the system enters at next-day open).
