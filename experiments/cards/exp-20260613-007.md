# Experiment Card: exp-20260613-007

## Summary

13F institutional holdings never accumulate as real data: the kova sidecar writes only skipped placeholders because it needs a CUSIP->ticker map and a SEC zip whose hardcoded URL template ({year}q{quarter}) silently broke when SEC switched to filing-window naming (01mar2026-31may2026) around 2024 - undetected because no env config ever triggered the download. A universe-scoped issuer-name CUSIP map (free, from company_tickers titles) plus a window-aware downloader yields real per-ticker institutional holdings for ~79% of the broad universe, refreshing when each new ~quarterly filing window is released, without changing any trading rule.
