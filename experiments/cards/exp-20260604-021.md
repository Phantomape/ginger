# exp-20260604-021 PEAD Broad-Universe Paper Sleeve

**Status:** proposed

**Experiment ID:** `exp-20260604-021`

**Lane:** `alpha_search`

**Single variable:** Add a new `PEAD_BROAD_UNIVERSE_PAPER` default-off paper sleeve that triggers on EPS surprise ≥ 5% alone, applies a gap-cancel filter (skip if earnings-day gap > 3%), and holds 10 trading days. No MA50/RS/pre-event-underpricing/close-location filters.

---

## Hypothesis

The existing `POST_EARNINGS_UNDERPRICED_DRIFT_PAPER` sleeve is too restrictive for testing broad PEAD: it requires the stock to be already above MA50, have positive 20d RS vs SPY, have underperformed pre-event, and have a positive close location. These filters select a narrow "continuation + trend" subpopulation, not the academically-studied PEAD phenomenon.

A new separate sleeve (`PEAD_BROAD_UNIVERSE_PAPER`) that triggers on EPS surprise alone will:
1. Accumulate a broader forward sample of earnings-drift candidates
2. Not overlap with the existing sleeve's selection logic
3. Allow future comparison of pure-surprise vs. surprise+trend populations
4. Provide the first independent forward data needed to assess wide-universe PEAD

---

## Key Design Decisions

### Trigger (what fires)
- Report period EPS actual > EPS estimate by ≥ `min_surprise_pct` (default 5%)
- Detected via daily earnings snapshot transition (same mechanism as existing sleeve)
- Window: T+0 through T+2 (same day or up to 2 trading days post-report)

### Gap Cancel (what blocks)
- If earnings-day (T+0) open is > `gap_cancel_threshold_pct` (default 3%) above prior close, skip
- Rationale: prevents chasing institutionally-absorbed gap-ups; academic PEAD is about drift, not immediate repricing

### Price and Volume Floors
- Close ≥ `min_price` (default $5)
- Avg daily dollar volume (20d) ≥ `min_avg_dollar_volume` (default $10M)

### Deliberate Omissions vs Existing Sleeve
| Filter | Existing POST_EARNINGS_UNDERPRICED sleeve | This sleeve |
|---|---|---|
| MA50 trend filter | Required: close > MA50 | **Removed** |
| RS20 vs SPY | Required: RS20 > 0 | **Removed** |
| Pre-event RS | Required: RS20 ≤ 0 (underperformer) | **Removed** |
| Close location | Required: ≥ 0.55 | **Removed** |
| Event-to-signal excess | Required: ≥ 0 | **Removed** |
| Gap cancel | None | **Added** |

### Hold Period
- 10 trading days (same as existing sleeve; 5d was proven weak in exp-20260528-027/028)

### Entry Timing
- T+1 open (one trading day after earnings-confirmed snapshot date)

---

## Universe Limitation (Known)

The current implementation scans tickers in the production `ohlcv_dict` (~45 tickers), since earnings snapshots only exist for the production universe. True broad PEAD (Russell 1000 / SP500) would require:
1. A separate earnings-data expansion pipeline for wider universe
2. OHLCV fetching for hundreds of additional tickers at startup

This is documented as a known limitation. The initial value is:
- Accumulating forward evidence on the **existing universe** with a different filter design
- Establishing the sleeve infrastructure for future universe expansion
- Separating PEAD signal from the existing "trend + surprise" sleeve

- Kill switch designed and tested
