# Experiment Card: exp-20260730-001

## Summary

Fault recovery: a validated USAspending async download receipt can remain running across the UTC date boundary, but the accepted producer filters continuation by the caller run_date, so the next daily run ignores a still-valid job, can duplicate POST, and loses an irreplaceable forward calendar snapshot. Drain the single TTL-valid journal by its own frozen run_date and request before any current-day POST, consume the recovered dated snapshot, retire the completed receipt, then continue the current day; persist the existing fail-closed producer health into the dated non-OHLCV snapshot without changing signals, ranking, sizing, exits, or orders.
