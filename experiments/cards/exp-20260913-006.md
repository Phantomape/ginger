# Experiment Card: exp-20260913-006

## Summary

The news-propagation pair paper sleeve cannot settle any basket because load_pair_bars treats a stale warehouse frame (ohlcv_overlay rows for non-core tickers stop at 2026-04-24 with 100 rows) as present and therefore never consults the massive_history fallback that holds current bars for those tickers; the frozen rule is warehouse first then massive_history for tickers the warehouse cannot price. Repair: a warehouse frame whose last bar precedes the session anchor's last warehouse bar is treated as absent for that ticker so the whole ticker falls through to massive_history (raw bars plus split normalization, unchanged). Acceptance is correct implementation of the frozen rule verified by a unit test with an injected stale frame and a temporary massive db plus an outcome-blind identity projection of the five pending baskets (blocker kinds and missing-ticker counts only; no PnL read); it is not judged by any settled value.
