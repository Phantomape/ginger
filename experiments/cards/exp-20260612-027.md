## Post-Run Reflection

- Why did the result happen? The broad sample (617 source trades, 380 unique tickers, 7 allocator
  source families, 28 source x state cells) finally separated regime structure from single-name
  luck. Exactly one cell survived the predeclared ex-top-ticker screen:
  `industry_stable_core_flow x mixed|balanced|normal` — n=32 across 31 unique tickers (top ticker
  TOST only 20.9% of positive PnL), in-cell +2.93%/trade versus -0.22% in all other states of the
  same source, edge +3.14pp and ex-top edge +2.21pp, positive in all three windows both raw and
  ex-top. The near-misses validated the screen's discriminative power: lagged consensus x the same
  state failed exactly on APP's 51.4% share (reproducing exp-20260612-018/020), and compression x
  the same state collapsed from +2.3pp to +0.1pp once its top name was removed.
- Which near-neighbor retry is now forbidden? Gate-4ing the near-miss cells (consensus cell blocked
  on APP; compression cell single-name driven; broad_down laggard cell n=5); re-screening the same
  28 cells with relaxed thresholds or alternative state classifiers to manufacture survivors.
- What new evidence would justify a retry? None needed for the survivor — it proceeds directly to
  one frozen Gate 1-4 router experiment (bounded notional tilt on industry_stable_core_flow rows
  entered in mixed|balanced|normal, inside the accepted allocator stack, comparator =
  exp-20260611-005 accepted allocator, dual concentration guards). Known risk for that run:
  the cell is weakest in late_strong (+0.19%/trade), concentrating zero-regression risk there.
