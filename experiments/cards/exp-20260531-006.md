# Experiment Card: exp-20260531-006

## Summary

The composite cross-sectional alpha_score has monotonic forward-return predictive power on the FULL daily candidate universe (filled and unfilled), which exp-20260530-022 could not test because filled core trades concentrate into the top rank bucket. Scoring every ticker on sampled trading days across the canonical 3 windows and bucketing all (day,ticker) observations by alpha_score quintile/decile against 5/10/20-day forward returns reveals whether the ranking surface carries real cross-sectional alpha.
