## Result (accepted, 2026-08-25)

- Root cause: upstream migrated to www.iborrowdesk.com; the apex host keeps TCP but closes /api requests with no response (RemoteDisconnected, not an HTTPError), so every retry exhausted and the 5-consecutive-failure abort fired on every daily run from ~2026-07-21. fetch_state kept stale ok tags from earlier successes; the readiness observer correctly fail-closed on stale_pit_borrow.
- Repair: one-line API_URL repoint to https://www.iborrowdesk.com/api/ticker/{symbol}. 5 unit tests pass; payload schema unchanged (daily fields, latest_fee/available intact, data through 2026-08-24).
- Verification: targeted refresh of the 10 blocked pair short-side tickers 10/10 succeeded (+263 rows, all archived through 2026-08-24, within the 3-calendar-day readiness freshness bar); a standard 150-shard added +2580 rows across 89 tickers before hitting the www rate limit (http_444 after ~90 req at 1 req/s); abort-early is resumable by design.
