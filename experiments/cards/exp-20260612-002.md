# Experiment Card: exp-20260612-002

## Summary

Daily default-off paper sleeves starve because production runs on a 27-57 name fallback universe while accepted replays were validated on the ~1241-ticker sector-cache/warehouse universe. The warehouse only accumulates daily for tickers run.py fetches (90/8511 fresh; rest frozen at 2026-04-24), so universe unification requires a data plane: (1) incremental daily warehouse refresh for the broad universe, (2) generating the authoritative data/state/broad_market_paper/universe.json from warehouse freshness x sector cache, (3) feeding broad sleeve OHLCV from warehouse batch reads instead of per-ticker yfinance calls. This restores replay/daily universe parity and unblocks forward evidence accumulation (Gate 5 path) without changing any entry/exit/ranking/sizing rule.
