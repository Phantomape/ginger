## Post-Run Reflection

- Why did the result happen? The MTM/inference stack was already capable of
  reproducing the exp-20260712-006 smoke values, but the ordinary command still
  depended on the current open-position universe and a live yfinance earnings
  calendar. Freezing those behavior inputs, the earnings-snapshot map, source
  bundle, config/costs, and warehouse rowsets removed those mutable identities;
  both complete three-window passes then matched exactly.
- Which near-neighbor retry is now forbidden? Do not refresh inputs, replace
  the published artifacts, or reserve another ID merely to rerun the same
  source/data/config context. Do not describe the change from historical
  aggregate EV `7.8941` to `12.2698` as alpha gain; the two values cross the
  MTM protocol boundary and the current stack does not exactly reproduce every
  archived trade.
- What new evidence would justify a retry? A changed behavior source, strategy
  stack, dependency, cost contract, frozen universe/calendar, or warehouse
  rowset requires a new experiment and a new immutable baseline identity. A
  clean-release promotion additionally requires the bundled MTM/inference
  source to exist in a clean committed Git tree.
