# Experiment Card: exp-20260601-003

## Summary

The full-universe top-quantile alpha_score forward-return edge found in exp-20260531-006 is driven primarily by the momentum components (trend 0.30 + relative_strength 0.25) that the core entry rule already trades on, not by the expectation_revision / post_earnings_drift / theme_participation / breadth_alignment components. Bucketing the same 3551 (day,ticker) observations by EACH component score quantile and measuring 5/10/20-day forward-return spread isolates which components carry independent cross-sectional signal; if only trend/RS show a spread, alpha_score adds no new alpha over the existing core momentum logic.
