# Experiment Card: exp-20260724-002

## Summary

Fault recovery for a recurring upstream publish anomaly: the OnclickMedia daily forward options snapshot is single-shot, so transient upstream outages (HTTP 530/5xx) have permanently destroyed three full forward quote-days (2026-05-25, 2026-06-19, 2026-07-23; 6 more partial days) and the PIT contract correctly forbids backfilling forward vintage, making each lost day unrecoverable and starving the core_drawdown_flow_put_stabilization reopen counter at its binding options_complete stage. Adding bounded transient-error retries per request plus one bounded whole-snapshot second attempt inside the same nightly run converts brief upstream outages into successful same-calendar-day forward captures without changing any PIT contract, selector, ranking, sizing, exits, or orders.
