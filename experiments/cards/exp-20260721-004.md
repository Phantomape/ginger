# Experiment Card: exp-20260721-004

## Summary

Reopen counters for parked lanes are scattered across ticket reflections and memory files with no machine-readable surface, so every session re-derives them by hand and misreads thresholds (Q5>=12 vs the governing Q5>=20); and docs/meta_learning_state.md points at a calibration report that has never been generated despite 100 percent prediction coverage since 2026-07-14. Build a new reopen-readiness builder tool that emits data/reopen_readiness.json from canonical ledgers with declared thresholds, current counts, and stall detection; run the experiment-history calibration report once; and repair the meta-learning doc to a prediction-recording spec with minimum-sample and base-rate-skill guardrails instead of an unexecuted weekly Brier ritual.
