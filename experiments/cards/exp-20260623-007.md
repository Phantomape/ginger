# Experiment Card: exp-20260623-007

## Summary

Experiment-ID decontention failure: scripts/experiment.py new allocated exp-20260622-021, an ID already used today by the autonomous pipeline (owner alpha-explore, completed 2026-06-22T20:09Z, rejected closeout already committed in docs/experiment_log.jsonl). reserve_experiment reserved it as 'proposed' and a follow-up claim regressed the CLOSED/rejected experiment to claimed-by-another-owner. The O_EXCL ticket reservation did not collide despite experiments/tickets/exp-20260622-021.json already existing on disk (13:09). Likely root cause: the next-free-ID scan trusts the committed registry cache (which lacked the pipeline's still-uncommitted/untracked ticket), and/or the per-id lock + O_EXCL path does not treat an existing untracked ticket file (or an existing experiment_log.jsonl closeout) as occupied. Repair: the allocator must skip any ID that exists as a ticket file OR has a closeout row in experiment_log.jsonl, and reservation must hard-fail (not silently merge/overwrite) when a ticket for the target ID already exists.
