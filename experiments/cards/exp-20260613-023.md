# Experiment Card: exp-20260613-023

## Summary

Production data ingestion (SEC companyfacts, kova fundamentals, earnings snapshot, options chains, FINRA short interest) was narrow (~40-58 tickers) and/or frozen because each stream consumed the narrow data_universe (watchlist+pilots) and companyfacts refresh was env-gated off (KOVA_REFRESH_COMPANYFACTS=False), and one-shot backfills had no daily refresh owner. Widening every stream to the broad ~1229 universe feed and wiring each to attempt a fetch every production run eliminates silent staleness and prevents alpha distortion from a non-representative narrow sample. Measurement repair, not an alpha change: trade_enabled stays False, no orders/ranking/sizing/exits change.
