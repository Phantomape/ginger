# Experiment Card: exp-20260612-017

## Summary

Production data layout has four consolidation debts that make tooling miss or mistrust data: (1) the production-critical OHLCV warehouse lives under data/experiments/exp-20260519-030/ where it reads as disposable experiment output; (2) legacy earnings_snapshot copies at data root and legacy_root/ duplicate organized files and get picked up by daily_artifact_glob; (3) other legacy root-level copies (space_catalyst ledgers, universe_registry) shadow organized locations; (4) three observe-only sleeves (platform_rs20_no_gap, sec_10k_liquidity, space_catalyst) persist only nonstandard forward_watch/summary surfaces so standard state.json+snapshots.jsonl tooling skips them. Relocating the warehouse to data/warehouse/ (with LFS pattern + legacy fallback), deleting shadowed legacy copies, and adding a shared standard-layout writer used by the three sleeves consolidates the data plane without changing any trading rule.
