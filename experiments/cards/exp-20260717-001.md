# Experiment Card: exp-20260717-001

## Summary

The yfinance no-price negative cache only records the 'possibly delisted; no timezone found' log shape, so permanently dead tickers that emit 'possibly delisted; no price data found' (SATS/IAC/BK since 2025-06, CTRA/CUK/TPH since 2026-04, BOK/SFG since 2025-05 in the 2026-07-15 run log) are re-fetched at full lookback every daily run, wasting yfinance quota and contributing to same-run YFRateLimitError on live tickers (SPY, CTRA retries exhausted). Extending the recorder to also cache the no-price-data shape when the message's own request window spans >=25 days (a live ticker cannot produce a zero-row month; 14-day TTL and clear-on-real-data self-heal retained) stops the waste without risking false suppression of live tickers.
