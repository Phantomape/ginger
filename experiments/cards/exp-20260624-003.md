## Summary

Regime-conditioned held-book risk-budget overlay: apply the exp-20260623-026 overlay (15pct single-name risk cap + 30pct vol target, excess to cash) ONLY when the PIT market regime is NOT BULL, and hold static (full weights) when regime is BULL. Regime = production compute_market_regime() (SPY+QQQ vs 200d MA), evaluated PIT with trailing-only data at each monthly rebalance. Hypothesis: the gate keeps the drawdown protection in non-BULL windows while removing the bull-window return drag that made the always-on overlay EV-negative, so aggregate EV beats BOTH static and the always-on overlay. Observed-only; no core-strategy/order change.
