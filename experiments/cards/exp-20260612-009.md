# Experiment Card: exp-20260612-009

## Summary

Several daily data streams never accumulate or accumulate only by manual action: forward_tester is a manual CLI dead since 2026-02-20 and its only artifact consumer role is obsolete (operator workflow is prompt->GPT->import_advice); the OPENAI auto-call branch never runs (no key) yet investment_advice_*.json remains the nominal canonical artifact; broad_market_sector_map.json / sec_company_tickers.json / sec companyfacts cache have no daily-path refresher; kova companyfacts surface rides a never-refreshed cache because KOVA_REFRESH_COMPANYFACTS defaults off and refresh=False is hardcoded. Removing the dead path, making llm_prompt_resp the single canonical response artifact, and wiring throttled rolling refreshers restores trustworthy accumulation without touching any trading rule.
